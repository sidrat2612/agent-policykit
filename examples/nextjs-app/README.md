# Next.js App Example

This directory is reserved for a worked example of generating instructions for a Next.js web application.

Planned example outputs:

- `.github/copilot-instructions.md`
- `.github/instructions/project.instructions.md`
- `AGENTS.md`
- `.cursor/rules/project.mdc`
- `CLAUDE.md`
- `GEMINI.md`

Suggested local command:

```bash
agent-policykit generate --target copilot --target copilot-path --target agents-md --target cursor --target claude-code --target gemini-cli
```
